# DAIZEN 公式サイト（GitHub Pages 版）

株式会社大善（DAIZEN）のハウスクリーニング・エアコンクリーニングのサイトです。
サーバー不要の静的サイトで、GitHub Pages でそのまま公開できます。

| ページ | 内容 |
|---|---|
| `index.html` | トップ（サービス・カーペット動画・DAIZENメソッド・流れ・FAQ・会社概要・特商法） |
| `price.html` | 料金表（税別／税込の切り替え付き） |
| `booking.html` | Web予約（メニューを選ぶと概算金額を自動計算） |
| `movie.html` | カーペット動画の書き出し用ページ（ナビには出していません） |

## よく変更する場所

| 変えたいもの | ファイル | 場所 |
|---|---|---|
| 電話番号・メール・住所・SNS | `assets/site.js` | 先頭の `SITE` |
| 料金表 | `price.html` | `PRICES` |
| 予約フォームのメニューと金額 | `booking.html` | `CATEGORIES`（金額はすべて税込） |
| 10月キャンペーンの期限 | `booking.html` の `CAMPAIGN_UNTIL`、`index.html` の `data-until`、`price.html` の `until` | 期限を過ぎると自動で非表示 |
| 色 | `assets/style.css` | 先頭の `:root` |
| 動画の料金・電話番号 | `assets/carpet-movie.js` | 先頭の `PRICE` と `TEL` |

## 予約フォームを受け付けられるようにする（Googleスプレッドシート連携）

予約内容をスプレッドシートに保存し、お客様に確認メール、DAIZENに通知メールを送ります。

1. Googleドライブで新しいスプレッドシートを作成（名前は「DAIZEN Web予約」など）
2. メニューの「拡張機能 → Apps Script」を開く
3. 最初からあるコードを消して、このリポジトリの `Code.gs` の中身を貼り付けて保存
4. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ Googleアカウントへのアクセスを許可
6. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）をコピー
7. `assets/site.js` の `gasUrl: "",` の `""` の中に貼り付けて保存・公開（予約フォームと口コミ自動更新の両方に使われます）

> `Code.gs` を後から書き換えた場合は、「デプロイを管理 → 編集 → 新バージョン」で更新してください（URLは変わりません）。

## Google口コミ（★評価・件数）の自動更新

トップページの「★5.0（97件）」は、Apps Script が毎朝 Google から取得した最新の数字に自動で置き換わります
（取得できないときは HTML に書いてある数字のまま表示）。

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作り、請求先アカウントを設定
   （1日1回の取得なら無料枠内に収まります）
2. 「APIとサービス → ライブラリ」で **Places API (New)** を有効化
3. 「認証情報 → 認証情報を作成 → APIキー」でキーを作成し、「キーを制限」で API を Places API (New) のみに制限
4. Apps Script の「プロジェクトの設定（歯車）→ スクリプト プロパティ」に
   プロパティ `PLACES_API_KEY`、値に作成したキーを追加して保存
5. エディタで関数 `setupDailyTrigger` を選んで「実行」（初回は権限の許可が出ます）
   → 実行ログに「口コミを更新しました」と評価・件数が出れば完了。以後は毎朝6時台に自動更新されます。

> APIキーはコードやGitHubには書かず、必ずスクリプト プロパティに保存してください。

## カーペット動画

`assets/carpet-movie.js` が `<canvas>` に描画するアニメーション動画です（縦型 720×1280・約32秒）。
Googleビジネスプロフィールの動画（2023年5月投稿・31秒・ポリッシャー作業の1カット）を参考に、
カーペットページに書かれている実際の工程（ポリッシャー → ドイツ製洗剤でカプセル化 → リンサー吸引 → 乾燥）と
ビフォーアフター・料金・電話番号を入れて構成しています。

動画ファイルが必要なときは、PCのChromeで `movie.html` を開いて「動画ファイルとして保存」を押してください。
タブを開いたまま約32秒待つと mp4（Chromeのバージョンによっては webm）が保存されます。
