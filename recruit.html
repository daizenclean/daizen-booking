Mission / Vision / Value

DAIZENの企業理念

人に親切にする／楽しく暮らす／光り輝く人になる／魅力ある人になる。この目的のために活動します。

MISSION

我々は「心からの安心」を得て生き生きと暮らす。

VALUE

我々は「限りない幸せの価値」がある。

「次々と現れる幸福」の事象に繰り返し包まれます。この事象は家族・社会・未来に幅広く限りなく繰り返し及びます。素晴らしい限りない価値です。

Q&A

よくある質問

未経験でも本当に大丈夫ですか？

大丈夫です。オンライン研修（動画）と、先輩スタッフに同行する5日間の現場研修で基礎から学べます。エアコンクリーニング未経験者、エアコン取付け作業未経験者、ハウスクリーニング作業未経験の方も多数活躍しています。

研修はどんなことをするのですか？

オンライン研修（動画）と実務＆現場研修（5日間）の2つです。最終日のテストは、動画でしっかり学んでおけばほぼ間違いなく合格する内容です。

独立はできますか？

はい。エアコンクリーニング技術で独立、エアコン取付け技術で独立、どちらの道も応援しています。技術を完全にマスターするまで研修を受講でき、独立のご相談も受けています。

雇用の形態を教えてください。

業務委託です（定期清掃ヘルプメンバーはアルバイト・パート）。雇用保険などが気になる方は、小規模企業共済やiDeCoなどへのご加入をご検討ください。

勤務日数、勤務時間は？

ご自由に設定できます。1日4時間以内、週2〜3日からでもOKです。副業の方も歓迎します。

道具代金はいくら掛かりますか？

10〜12万円あればご用意可能です。必要なもののリストをお渡ししますので、Amazonなどで購入いただけます。

車を持っていないと仕事は出来ませんか？

月単位で借りられるレンタカーをご用意頂くか、メルカリ、ヤフオクなどで格安の中古車を購入するなどして作業車をご用意ください。今乗られている乗用車でも大丈夫です。小型車で十分です。
